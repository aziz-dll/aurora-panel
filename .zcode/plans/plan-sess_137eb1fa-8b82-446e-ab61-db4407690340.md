# Aurora — Habits Build/Quit, Reminders, Tile Grid, Full EN, AuroraStorage Plugin, Real Widgets

## 1. Habits: Build/Quit, Reminders, Tile Streak Grid, Color/Icon Picker

### Veri modeli (`src/lib/types.ts`)
Mevcut `Habit` tipi zaten `type: 'build' | 'quit'` ve `icon: string`, `archived?: boolean` içeriyor. Tutarsızlık: Habits.tsx `habit.emoji` kullanıyor ama tip `icon`. **Düzeltme:** `icon` adı kalsın, Habits.tsx'i güncelle. Ayrıca `frequency` zaten `daily | weekly | x-per-week | x-per-month` — bunu zaten destekliyor, helper'lar hazır.

### Build+Quit akışı
- **Build:** Streak 21+ güne ulaşınca habit otomatik **"built"** rozeti alır (`habit.builtAt: string` — types'a ekle). Bugünkü kartın yanında 🎉 emoji rozeti. "Built" listesine taşınmaz, sadece görsel işaret.
- **Quit:** Special habit. Tile'a tıklayınca `habitSetCompletion(log, habit, iso, false)` (no-slip). Streak = ardışık "kayma yok" günleri. `habitStreak` `quit` için 365 günlük `false` zinciri sayar.
- **Archive:** `habit.archived = true` → ana sayfada gizli, details'da "Archived (X)" altında gösterilir. İstatistik korunur.

### Renk/Icon seçici
- `HABIT_ICONS` (lucide isimleri) zaten `habits.ts`'de var. `HABIT_COLORS` da var. NewHabitForm'a **icon picker** (lucide render'lı grid) ve color picker ekle — mevcut emoji picker kaldırılsın.
- Icon grid: 5x4 = 20 lucide ikon (drop, book, dumbbell, flame, moon, sun, brain, pen, target, zap, heart, coffee, smile, music, book-open, footprints, salad, pill, cigarette-off, archive).
- Renk: 12 palette (mevcut 8'i + ek 4).

### Tile streak grid
- Her habit için collapsible: altında **30 günlük renk skalası** (GitHub contribution graph). Renk kademesi:
  - Skip (expected değil): gri
  - Empty: açık gri
  - Build+done: açık renk (habit.color %30)
  - Build+streak: artan doygunluk
  - Quit+no-slip: yeşil tonu
  - Quit+slip: kırmızı tonu
- Helper: `tileColor(habit, iso, log)` → CSS class.
- Tıklanınca gün toggle (geçmiş günler için sadece read-only, sadece bugün toggle).

### Reminder
- `reminderTime` zaten Habit tipinde. `buildDrafts()` (reminders.ts) habit'leri de gezsin: `habit.reminderTime && !habit.archived` → her habit için bugün + `reminderTime` ile bir draft.
- `postStateToParent` payload'ına `habits` ekle.
- `apk-loader/index.html scheduleAll()` habit draft'larını da planlasın.

### UI
- NewHabitForm'a: type (build/quit) segmented control, frequency (4 seçenek), target count (x-per-week için "Haftada 3 gün"), weekdays grid (weekly için), reminder time, icon picker, color picker.
- HabitCard tıklanınca bugünü toggle. "🎉 Built" rozeti 21+ günlük streak'te. "📦 Archived" rozeti arşivde.
- "Show streak grid" toggle her kartın altında — açılınca 30 günlük 5x6 grid.

## 3. AuroraStorage Capacitor Plugin (SharedPreferences)

### Java tarafı (`android/app/src/main/java/com/gh0st/okulpaneli/AuroraStoragePlugin.java`)
```java
@CapacitorPlugin(name = "AuroraStorage")
public class AuroraStoragePlugin extends Plugin {
  private static final String PREFS = "aurora_storage";
  @PluginMethod
  public void set(PluginCall call) {
    String key = call.getString("key");
    String value = call.getString("value");
    getContext().getSharedPreferences(PREFS, Context.MODE_PRIVATE)
      .edit().putString(key, value).apply();
    call.resolve();
  }
  @PluginMethod
  public void get(PluginCall call) {
    String key = call.getString("key");
    String value = getContext().getSharedPreferences(PREFS, Context.MODE_PRIVATE)
      .getString(key, null);
    call.resolve(new JSObject().put("value", value));
  }
  @PluginMethod
  public void remove(PluginCall call) { ... }
  @PluginMethod
  public void keys(PluginCall call) { ... }
}
```

### Register
- `MainActivity.java` `init` içinde `registerPlugin(AuroraStoragePlugin.class)`.

### JS tarafı (`src/lib/auroraStorage.ts`)
```ts
import { registerPlugin } from '@capacitor/core';
export interface AuroraStoragePlugin {
  set(opts: { key: string; value: string }): Promise<void>;
  get(opts: { key: string }): Promise<{ value: string | null }>;
  remove(opts: { key: string }): Promise<void>;
  keys(): Promise<{ keys: string[] }>;
}
export const AuroraStorage = registerPlugin<AuroraStoragePlugin>('AuroraStorage');
```

### Widget veri akışı
- `widgetSync.ts` `syncWidgets(db)` artık `AuroraStorage.set({ key: 'widget-data', value: JSON.stringify(fullData) })` çağıracak. Native tarafta `AuroraStorage` SharedPreferences'a yazar.
- **AppWidgetProvider Java tarafı:** widget güncelleme broadcast'i alındığında `AuroraStorage.get({ key: 'widget-data' })` ile oku, JSON parse et, RemoteViews'e yaz.

## 4. 3 Widget — Gerçek Veri + AuroraStorage

### Plugin genişletmesi
- AuroraStorage'a `notifyWidgets(opts: { provider: string })` ekle — native tarafta `AppWidgetManager.getInstance(context).updateAppWidget(ComponentName(context, TodosWidget.class), ...)` çağıracak.
- `widgetSync.ts`'te `AuroraStorage.set` + `AuroraStorage.notifyWidgets` ardarda çağrılır.

### TodosWidget
- Layout: 3 satır (title + 3 todo item). `setTextViewText(R.id.widget_todos_item_1, "...")` ile.
- `onUpdate` + `onAppWidgetOptionsChanged` (resize için) → `AuroraStorage.get({ key: 'widget-data' })` → JSON parse → ilk 3 açık todo → RemoteViews setText.
- APK kabuğunda refresh butonu koymadan `onDataSetChanged` ile ListView adaptörü yenilenebilir, ama ilk aşamada statik 3 satır yeterli.

### ScheduleWidget
- Layout: bugünkü 3 ders (saat + ad + oda).
- `onUpdate` → AuroraStorage'dan schedule verisini çek → bugünün gününe göre (0=Mon..6=Sun) `db.lessons.filter(day === todayDow)` → sırala, ilk 3'ü göster.
- ScheduleWidget verisini de `widget-data`'ya koy: `db.lessons` zaten DB'de.

### ServerWidget (yeni)
- Layout: 3 halka/çubuk — pil % + RAM % + ROM %.
- `onUpdate` → AuroraStorage'dan `battery`, `memory`, `disk` → hesapla → RemoteViews.
- `useSystemStats` 15 sn polling'in `widgetSync`'i tetiklemesi: `useSystemStats`'tan dönen `battery`, `memory`, `disk` zaten hesaplanmış, `widgetSync.updateStats(stats)` ile widgetData'ya yaz. Server sayfası açıkken poll ediyor — widget'lar bu yüzden 15 sn'de bir tazelenir.
