## 2) RAM → ROM + SD kart
### 2a. server.mjs — yeni endpoint'ler
- `/api/memory` korunur (RAM, mevcut davranış).
- `/api/storage` eklenir: `/storage/emulated/0` mount'unu `df -k -P` ile parse eder, `{mount, total, used, free, unit: 'GB'}` döner.
- `/api/storage/sd` eklenir: `/storage/<UUID>` satırı varsa depolama, yoksa `{present: false}`.
- `df -k -P` kullanılır (1 KB blok, POSIX sütun düzeni — `-h`'den güvenli parse).
- Aynı `df` çıktısını iki endpoint için 30 sn'lik basit bir in-memory cache ile yeniden kullan (polling ek yükünü azaltır).

### 2b. src/lib/termux.ts — client tarafı
- `MemoryInfo` korunur.
- Yeni `StorageInfo` tipi: `{mount: string | null, total: number | null, used: number | null, free: number | null, unit: 'GB'}`.
- `SdInfo = StorageInfo & { present: boolean }`.
- `termux.storage()` ve `termux.storageSd()` eklenir.

### 2c. src/pages/Dashboard.tsx — UI
- "Cihaz" kartında RAM satırı silinir.
- Yerine iki satır: **Depolama** (dahili, progress bar + GB), **SD kart** (varsa, küçük satır; yoksa "SD kart takılı değil" gizli mesajı).
- Mevcut `BatteryRing` deseni korunur; yanına küçük bir `StorageRing` veya sade metin+yüzde tercih edilecek — Notion sadelik için **sade metin + ince progress bar** (`h-1 bg-line` arka plan + `bg-accent` dolgu) kullanacağım.

## 3) Build + APK + tar akışı
`scripts/build-apk.sh` zaten APK'yı `Aurora.apk` (dashboard kökü) olarak kopyalıyor. Eksik olan: tar'a APK dahil değil.

- `scripts/build-apk.sh` scriptinin sonuna `echo "✓ APK dashboard köküne kopyalandı"` mesajı bırakılır (zaten var).
- `package.json` `pack` scripti güncellenir:
  ```
  "pack": "tar czf okul-paneli-deploy.tar.gz dist server.mjs start.sh Aurora.apk"
  ```
- `build` (npm) → tsc + vite → `dist/` hazır.
- `apk` (npm) → `npx cap sync` + gradle assembleDebug + `Aurora.apk` kopyala.
- `pack` (npm) → `dist/ + server.mjs + start.sh + Aurora.apk` → `okul-paneli-deploy.tar.gz`.

Yeni "all-in-one" script eklemiyorum (derleme 5-10 dk + JDK 21 + Android SDK gerektiriyor; CI dışında kafa karıştırır). Sıralı çalıştırma: `npm run build && npm run apk && npm run pack`.
